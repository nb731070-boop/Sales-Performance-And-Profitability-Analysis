# Sales-Performance-And-Profitability-Analysis
Interactive Power BI Sales Performance Dashboard featuring data cleaning and transformation using Power Query, KPI analysis, regional and category-wise sales insights, discount analysis, and profitability tracking to support data-driven business decisions

## Project Overview
An interactive Power BI dashboard built to analyze sales performance, discounts, profitability, and regional trends.

## Tools Used
- Power Query
- Microsoft Power BI
- DAX / Power BI measures
- Data visualization

## Key Performance Indicators
- Total Orders
- Gross Sales
- Total Discount
- Net Sales
- Total Profit

## Dashboard Visualizations
- Monthly Sales Trend
- Sales by Region
- Sales by Category
- Payment Mode Analysis
- Salesperson Performance
